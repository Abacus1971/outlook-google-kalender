Personvernerklæring

Outlook Google Kalender Synk er utviklet for privat bruk.

Programmet leser kalenderavtaler fra Microsoft Outlook og oppretter eller oppdaterer tilsvarende avtaler i brukerens egen Google Kalender.

Programmet kjører lokalt på brukerens PC. Autorisasjonsinformasjon og koblinger mellom kalenderavtaler lagres lokalt.

Kalenderopplysninger sendes til Google Calendar API for å gjennomføre synkroniseringen. Det brukes ingen egen ekstern server til å behandle kalenderdata.

Integrasjonen er ikke tilgjengelig for andre brukere.
